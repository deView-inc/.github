# deView

Платформа для проведения технических собеседований с видеочатом и живым кодингом.

---

## 📖 О проекте

**deView** — это онлайн-платформа, которая объединяет видеочат, текстовый чат и редактор кода в одном окне.

Всё, что нужно для технического интервью, — здесь:

- Видеозвонок с собеседником
- Чат для переписки
- Редактор кода с запуском программ

Больше не нужно переключаться между Zoom, Google Docs и онлайн-компилятором. Всё работает в одном месте.

---

## 🎯 Для кого это

### Компании, которые нанимают разработчиков

- Проводите собеседования без лишних инструментов
- Кандидат пишет код, вы видите процесс в реальном времени
- Всё записывается, можно пересмотреть позже

### Технические рекрутеры и HR

- Смотрите, как кандидат мыслит
- Оценивайте навыки в действии
- Упрощайте процесс найма

### Кандидаты

- Никаких лишних программ — всё работает в браузере
- Ссылка на интервью приходит на почту
- Просто переходите и начинаете собеседование

### Фрилансеры и независимые разработчики

- Демонстрируйте свои навыки заказчикам
- Проводите технические созвоны с кодом
- Обсуждайте задачи и показывайте решения
